For a diff-target question, any claimed counterexample must be caused by a change in the displayed diff. Before reporting one, compare the evidence with the displayed base and explain which diff hunk causes the counterexample. A cited current line that is unchanged from the base is not a counterexample merely because its file has other changes; unchanged current code may only explain a changed hunk's effect. For an absence caused by deletion, state the complete affected domain inspected. An affected file's failure to define or prove broader project behavior does not establish a counterexample.
